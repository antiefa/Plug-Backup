# Plug & Backup

Резервное копирование выбранных папок на сменные носители (флешки, SD-карты, внешние диски) для Linux Mint 22 Cinnamon — одной кнопкой или автоматически при вставке носителя.

## Возможности

- Профиль на каждый носитель: носитель узнаётся по UUID, задания — пары «папка на компьютере → папка на носителе».
- Три режима копирования: зеркало с корзиной версий, зеркало, накопление. Копирование — rsync, переносятся только изменения.
- Защиты: метка профиля на носителе (без неё ничего не удаляется), пустой источник, массовое удаление, проверка места, имена файлов для FAT32/exFAT/NTFS, отключение носителя во время записи.
- Предпросмотр, прогресс, остановка, журнал запусков.
- Значок в трее, уведомления, автоматический запуск при вставке с отсчётом и тихой проверкой изменений, запуск при входе в систему.
- Восстановление в исходные или другую папку; заменяемые файлы откладываются.
- Шифрование: носитель целиком (LUKS) или зашифрованная папка на обычном носителе (gocryptfs); пароли — в связке ключей.
- Интерфейс и справка на русском и английском.
- Командная строка: `--list`, `--backup <профиль>`, `--check`, `--hidden`, `--version`.

## Требования

Linux Mint 22 / Ubuntu 24.04: Python 3.12, GTK 3 (PyGObject), UDisks2, rsync, libnotify, libsecret, cryptsetup, XApp.StatusIcon или AyatanaAppIndicator3.
Необязательно: `gocryptfs` и `fuse3` (зашифрованная папка), `gnome-keyring` (хранение паролей).

## Сборка и установка

```sh
./build-deb.sh                                   # → dist/plugbackup_<версия>_all.deb
sudo apt install ./dist/plugbackup_<версия>_all.deb
```

Версия задаётся в `plugbackup/__init__.py`.

## Переводы

```sh
./tools/update-po.sh                             # обновить po/plugbackup.pot и po/ru.po
```

Строки в коде — на английском, русский перевод — `po/ru.po`. Справка — `plugbackup/help_ru.py` и `plugbackup/help_en.py`.

## Тесты

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -t .
```

Тесты работают только с временными папками. Интеграционные тесты пропускаются по умолчанию:
- `PLUGBACKUP_GOCRYPTFS_TESTS=1` — настоящий gocryptfs (FUSE-монтирование во временной папке);
- `PLUGBACKUP_IMAGE_TESTS=1` — образы файловых систем через UDisks2.

## Структура

```
plugbackup/core/   ядро без интерфейса: носители, профили, rsync, движок, восстановление, журнал, шифрование
plugbackup/ui/     интерфейс GTK 3: окно, страницы, диалоги, трей, автоматика
plugbackup/cli.py  командная строка
data/              ярлык и значки
po/                переводы
tests/             тесты
tools/             служебные скрипты
build-deb.sh       сборка пакета .deb
```

## Где хранятся данные

На компьютере: `~/.config/plugbackup/` (настройки и профили), `~/.local/state/plugbackup/log/` (журнал), `~/.local/share/plugbackup/restore-backup/` (файлы, отложенные при восстановлении).

На носителе: `PlugBackup/` — копии заданий, `.versions/` (корзина версий) и `.plugbackup/` (метка профиля); при шифровании папки — то же внутри `PlugBackup.enc/`.
