# Сборка Plug & Backup для Windows

## Ручная сборка

Нужны Windows x64, Python 3.8.10, Inno Setup 6 и доступ к PyPI. Откройте PowerShell в корне репозитория и выполните:

```powershell
choco install innosetup --yes
.\packaging\windows\build.ps1
```

Скрипт создаёт виртуальное окружение `packaging\windows\.venv-build`, устанавливает закреплённые зависимости из `requirements-build.txt`, компилирует переводы из `po\*.po`, запускает PyInstaller и Inno Setup. Установщик и `SHA256SUMS` появятся в `packaging\windows\dist`. Сверить контрольную сумму можно командой `Get-FileHash -Algorithm SHA256 .\packaging\windows\dist\PlugBackup-*-setup.exe`.

Сборка на Python 3.8.10 выбрана для заготовки Windows 7 SP1. Python 3.8.10 — последний выпуск 3.8 с готовым Windows-установщиком; `setup-python` получает его для матричного значения `3.8`. PyInstaller 6.22.3 поддерживает Python 3.8 и новее, PyQt5 5.15.11 предоставляет Windows x64 wheel для CPython 3.8, а `PyQt5-Qt5==5.15.2` фиксирует Qt версии 5.15.2. Выбранная связка следует ТЗ для Windows 7; запуск этой сборки на Windows 7 ещё требует ручной проверки.

## CI

`.github/workflows/ci.yml` запускает полный `unittest` на Linux с системным Python 3.12, отдельный прогон на Python 3.8 без GTK и матрицу Windows 2022 на Python 3.8 и 3.12. Loop-интеграция и тесты gocryptfs включаются только переменными окружения, поэтому в CI не запускаются. На Windows тесты, помеченные зависимостью от rsync, пропускаются через `shutil.which("rsync")`.

`.github/workflows/windows-build.yml` запускается вручную через `workflow_dispatch`: устанавливает Inno Setup через Chocolatey, собирает установщик на Python 3.8 и загружает установщик с `SHA256SUMS` как артефакт. CI не публикует релиз.

## Ограничения

- В установщике нет подписи издателя. Windows SmartScreen может показать предупреждение о неизвестном издателе; сверяйте SHA-256 установщика с `SHA256SUMS`.
- Для Python 3.8 на Windows 7 SP1 требуется обновление KB2533623 (или заменившее его обновление). UCRT из KB2999226 нужен компонентам, собранным с зависимостью от Universal CRT; в составе PyInstaller и Qt есть нативные компоненты, поэтому для неподновлённой Windows 7 следует установить это обновление. Уверенность в KB2533623 высокая (указан документацией Python), в необходимости KB2999226 именно для этой упакованной сборки — средняя; готовый установщик проверяется на Windows 7 отдельно.
- Точка входа `plugbackup.qt.app:main` пока отсутствует. В таком состоянии оконная сборка показывает ясное сообщение; CLI-сборка остаётся доступна.
- Для удаления настроек деинсталлятор спрашивает отдельным диалогом «Да/Нет», при открытии выбран ответ «Нет». Inno Setup не предоставляет штатного флажка на шаге удаления; подтверждение можно дать только отдельным кодом деинсталляции.
- Сборка не подписывается и не является релизом. Windows Server 2022 не заменяет обязательную ручную проверку на Windows 7 и Windows 11.
